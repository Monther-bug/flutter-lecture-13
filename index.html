“Ephemeral” means short-lived; it is the word the Flutter docs use (docs.flutter.dev/data-and-backend/state-mgmt/ephemeral-vs-app). Quick quiz: “The selected page in a PageView?” (usually local) “The app language?” (shared). There is no perfect rule: if only one widget needs it, keep it local.

Mobile App Development · Lecture 13

These numbers are real: a shop page with 5 products and a cart badge. v2 keeps the count in one shared place (Flutter's built-in ValueNotifier). We ran both versions in a Flutter test and counted every widget whose build() ran after one "add". v1: the 8 widgets we wrote plus everything inside them (each ListTile and IconButton is made of many small widgets), 366 in total. v2: 7.

Is setState bad? No. At 60 frames per second Flutter has about 16 ms for each frame, and a phone rebuilds a few hundred widgets quickly. The cost grows with the page: long lists, big screens and animations are where extra rebuilds hurt.

Students can see the same counts themselves: DevTools, Performance page, "Track widget build counts", then "Rebuild Stats".

Install Provider · 1 of 2

Add Provider to your project: one command

  1. Open your Flutter project in VS Code
  2. Open the terminal: View → Terminal
  3. Type flutter pub add provider and press Enter
No terminal? Press Ctrl + Shift + P (Cmd on Mac), choose Dart: Add Dependency, and type provider.

Wrap-up

Summary

Today you learned

  • State = data that changes and affects the screen; UI = f(state)
  • Your screen is a widget tree of parents and children
  • setState rebuilds its widget and everything inside it (71 widgets for one tap); const widgets are skipped
  • Local state → setState; shared state → state management, where only the listeners rebuild (366 → 7)
  • Many tools, one idea: Provider, Riverpod, Bloc, GetX. Our class: Provider
  • Install it with flutter pub add provider
